# Simulation code (data generators)

MATLAB and Python code that **generates the synthetic dynamics** consumed by the VAE
systems under `simulations/`. Each subfolder produces the trajectories and the parameter
files (`.mat` / `.npz`) for one model family. Run these first if you want to regenerate
simulations from scratch; otherwise the pre-generated arrays are on Zenodo (see
[`../DATA.md`](../DATA.md)) and the small parameter files are kept in-repo alongside each
system.

## Correspondence to systems

| Subfolder | Model | Feeds system | Parameter files (kept in-repo) |
|---|---|---|---|
| `bounded gLV/` | bounded gLV (bgLV) | `simulations/VAE_gLV_simulation` (bgLV) | `saved_sims/bgLV/I*/bounded_O*_I*.mat` |
| `dispersal gLV/` | dispersal gLV (dgLV) | `simulations/VAE_gLV_simulation` (dgLV) | `saved_sims/dgLV/I*/dispersal_O100_I*.mat` |
| `patchy dynamics/` | spatial gLV (sgLV) | `simulations/VAE_gLV_simulation` (sgLV) | `patchy dynamics/initialization/*.mat` (bundled here) |
| `plasmid_simulation/` | plasmid gLV (pgLV) | `simulations/VAE_gLV_simulation` (pgLV) | `pcf/*.npz` (bundled here) |
| `consumer resource/` | MacArthur MiCRM | `simulations/consumer_resource` | `saved_sims/I*/inits.mat`, `params.mat` |
| `network sparsity/` | network-structured bgLV | `simulations/network_effect` | `saved_sims/I*/bounded_O100_I*.mat` |

Systems **not** listed here have no MATLAB generator by design:
`simulations/stochastic_logistic` is generated by its own `simulation.ipynb`
(→ `saved_sims/I*/params_I*.pkl`), and `simulations/short_sequence` reuses the gLV data.

## Notes
- **`bounded gLV/gen_para.m`**: the `save(...)` call (line 94) is commented out — uncomment
  it to re-emit the `bounded_O*_I*.mat` parameter files. `gen_para_10_mem.m` saves normally.
- `consumer resource/lib/` holds the shared MiCRM routines used by `gen_data_mcrm.m`;
  this library is based on the `mcrm` model by J. Goldford
  (https://github.com/jgoldford/mcrm) — see `consumer resource/README.md`.
- `patchy dynamics/sgLV_v04a.m` writes many intermediate `.mat` (Cini, muVec,
  speciesAssignments, colormaps) into its `initialization/` folder during a run.
- Requires MATLAB for the `.m` families; the plasmid generator (`parallel_pcf.ipynb`) runs
  under the same Python environment as the rest of the repo.
